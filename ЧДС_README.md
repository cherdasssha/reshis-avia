## Запуск без установки программ

1. Распакуйте архив.
2. Дважды нажмите **Открыть_в_браузере.html**. Это автономная версия сайта, в которой уже встроены оба CSV-файла из этапа ИИ. Интернет не требуется.
3. Выберите направление, дату с **01.06.2026 по 01.07.2026** и цену билета. Результат и график пересчитаются сразу.
4. Кнопка «Установить рекомендованную цену» использует медианную оптимальную цену из `my_forecast.csv` (квантиль 0.5).

## Размещение на хостинге

Файлы `index.html`, `styles.css`, `app.mjs`, `core.mjs`, `my_forecast.csv`, `routes.csv` надо поместить вместе в корень сайта. При открытии через HTTP(S) файлы автоматически загрузятся. Как статический хостинг можно использовать GitHub Pages, Cloudflare Pages или любой другой HTML-хостинг. Версию `Открыть_в_браузере.html` также можно разместить отдельно как статическую страницу.

## Формула по условию турнира

```text
желающих = max(0, 0.5_base_demand - price_sensitivity * (price - base_price))
продажи = min(seats, желающих)
свободно = seats - продажи
```

Для графика используется та же формула с каждым квантилем `0.1_base_demand`–`0.9_base_demand`. Пунктирная горизонтальная линия — вместимость. Медиана графика соответствует основному числу желающих.

Количество пассажиров, показанное в интерфейсе, округляется для удобства чтения; внутри модели используется вещественное значение ожидаемого спроса.

Дополнительно выведены оценочные выручка и вклад после переменных затрат. Это не полная прибыль авиакомпании: фиксированные затраты не учтены.

## Реальные данные

* `my_forecast.csv` — прогноз пользователя из ML-части турнира: 155 записей, 5 направлений, даты 01.06–01.07.2026, 9 квантилей.
* `routes.csv` — параметры направлений и чувствительность спроса к цене.

## Использование ИИ

Для создания и проверки веб-интерфейса применялся ChatGPT (GPT-6). Прогноз в CSV подготовлен в Google Colab с использованием AutoGluon TimeSeries, финальная модель — DirectTabular. На самой странице обучение не выполняется: все расчёты — JavaScript по предоставленным прогнозам.
